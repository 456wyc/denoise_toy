# 降噪耳机小软件（软件主动降噪 ANC）

把**普通耳机 + 一个麦克风**变成一副"降噪耳机"的小软件：
用麦克风捕捉环境噪声，实时做相位反转（180°）生成反相波，再由耳机播放，
反相波与原始噪声在耳内叠加相消，从而减弱噪声。

> 这是**前馈主动降噪（feedforward ANC）**的教学/演示实现。
> 它能真实工作，但效果强烈依赖两点：**低延迟** 和 **麦克风贴近耳朵**（见下文）。

---

## 原理

```
环境噪声 ──► 麦克风采样 ──► 相位反转(取负) ──► 耳机播放
                                             │
原始噪声 ───────────────────► 耳内 ◄─────────┘
                           （反相波与噪声叠加相消）
```

只要反相波与原始噪声**同幅、相位差 180°**，两者相加即为零，噪声被抵消。

## 安装

环境：Windows（Python 3.10+）。已安装 `numpy`，只需补 `sounddevice`。

```powershell
# 在项目目录下（推荐用虚拟环境）
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`sounddevice` 是 PortAudio 的 Python 封装，Windows 下 pip 会一并带上 PortAudio 运行库，
无需单独安装。

## 使用步骤（关键：麦克风摆放）

1. **把麦克风贴近耳朵**：例如把一个领夹麦/小电容麦塞进耳机耳罩内侧、振膜朝外；
   耳塞式耳机则把麦固定在耳塞旁、朝外。目标是让麦克风采到的信号 ≈ "即将进入耳朵"的噪声。
   - ⚠ 用笔记本自带麦克风、桌面麦克风**基本无效**——它采到的不是耳内噪声。

2. **先切到「监听 Monitor」模式**：此时麦克风声音会透传到耳机。
   如果能在耳机里清晰听到环境声，说明麦克风摆位正确、通路正常。

3. **切到「降噪 ANC」模式**：耳机里会播放反相波。环境中的**低频噪声**
   （空调、风扇、引擎轰鸣、键盘低鸣等）应明显减弱。

4. **调「降噪强度」**：默认 1.0。若觉得噪声反而变大，可微调增益（0.8~1.2 之间试），
   找到最接近"抵消"的幅度。

5. **（可选）混合音乐**：点「选择 WAV」加载音乐，降噪的同时正常听歌。

## 参数与调优

| 参数 | 说明 |
| --- | --- |
| 块大小 | 越小延迟越低、可抵消频率越高，但过小会爆音（欠载/溢出计数增加）。默认 128，可试 64/256。 |
| 采样率 | 48 kHz 是常用折中；96 kHz 对降噪上限提升有限，反而增大负载。 |
| 延迟档 | `low` 优先。若 `low` 下频繁爆音，换 `high` 求稳。 |
| 降噪强度 | 反相波幅度。默认 1.0；过补偿/欠补偿都会减弱效果。 |
| 低通(只抵消低频) | 反相波的低通截止频率，默认 150Hz。因为延迟决定了可抵消频率上限（约 1/(4×延迟)），高于上限的频率不仅抵消不了，还会被当成额外噪声放大——这正是"扩音器感"的来源。把它砍掉后更安静、更接近真实 ANC。延迟越低可把上限调越高。 |

底部状态栏会显示：**往返延迟**、输入/输出电平、欠载/溢出次数、削波次数。
往返延迟越低，降噪频段越宽（粗略上限 ≈ 1/(4×延迟)，例如 10ms ≈ 25Hz）。

## 局限与提升空间

1. **延迟是硬约束**。本程序走 PortAudio 的 WASAPI **共享**模式，往返延迟通常 10~30ms，
   因此主要抵消**低频**噪声（空调、风扇、引擎、机械轰鸣等），对中高频人声/高频啸叫基本无效。
   进一步降低延迟的方向：
   - 使用 WASAPI **独占**模式或 ASIO 驱动（需在 PortAudio 层配置 exclusive 参数，或改用 ASIO 的 SDK）；
   - 用 C/C++/Rust + 直接访问 WASAPI/ASIO 重写核心，把往返延迟压到几毫秒量级；
   - 减小块大小、提高线程优先级。

2. **麦克风摆位**决定成败。前馈 ANC 要求麦克风在耳道附近、朝外。摆不好不仅不降噪还会增噪。

3. **频率相位**。相位反转是最简实现，未做频域相位补偿/自适应滤波（LMS）。
   若要更接近商用 ANC，可用 **自适应 LMS/FxLMS 滤波**替代简单取负，动态跟踪噪声。

4. **硬件 ANC 仍是上限**。商用降噪耳机用专用 DSP 芯片 + 耳内误差麦克风（反馈 ANC），
   延迟在微秒级。本软件是"能跑通、能体验原理"的演示，而非替代硬件方案。

## 常见问题

- **听起来像"扩音器"、没有降噪感**：先记住一个关键事实——**相位反转本身人耳听不出来**，
  一段正弦波和它反转 180° 后的波听感完全一样；反转只有在"反相波与原噪声在耳膜处相遇"时才体现为相消。
  所以"像扩音器"意味着反相波没有抵消、而是在原噪声上又叠了一份声音。按顺序排查：
  1. 确认模式是「降噪 ANC」而不是「监听」（监听就是麦克风放大器，属正常现象）；
  2. 关闭 Windows 的「侦听此设备」：麦克风属性 → 侦听 → 取消勾选"侦听此设备"（否则 Windows 自己把麦克风放出来，和本软件叠加=双重放大）；
  3. 输入选真正的「麦克风」，别选「立体声混音」/「麦克风阵列」/「MIDI」；
  4. 麦克风必须塞进耳罩/耳塞旁、朝外贴近耳朵；离耳朵越远越像放大器；
  5. 降低「低通」截止频率（如 80~150Hz），只让软件抵消它真正能抵消的低频。
- **启动报"设备不支持/被占用"**：先 `--list` 确认设备索引；关闭占用该设备的其他程序（浏览器/会议软件）。
- **没有任何声音**：确认模式不是「关闭」；用「监听」模式排查通路；检查系统是否把耳机设为默认输出。
- **噪声反而变大**：麦克风离耳朵太远、增益过大、或往返延迟过高导致反相波变成"同相叠加"。
  降低增益、缩短延迟、把麦克风更贴近耳朵。
- **持续爆音/咔哒声**：块太小或 `low` 延迟档太激进，调大块大小或改 `high`。
